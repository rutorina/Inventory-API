# RutInventory: frontend

React 19 + React Router + Tailwind CSS v4, built with Vite.

```bash
cp .env.example .env   # VITE_API_URL=http://localhost:5123
npm install
npm run dev            # http://localhost:5173
```

The API must be running. See the [main README](../README.md) for full setup, features and the API reference.
